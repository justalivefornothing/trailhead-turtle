          Language reference
          

            
FD n · BK n
move forward / back

            
RT a · LT a
turn right / left (degrees)

            
PU · PD
pen up / down

            
HOME · CLEAR
return to centre · wipe the trail

            
SETXY x y · SETHEADING a
jump / face a direction

            
SETCOLOR c
palette 0–15 or "coral, "#ff8800

            
SETWIDTH w
pen width

            
REPEAT n [ … ]
loop; REPCOUNT is the iteration

            
IF cond [ … ]
with < > = <= >= <>

            
TO name :a :b … END
define a procedure; STOP exits

            
MAKE "x expr
set a variable, read it as :x

            
+ - * / ( )
RANDOM n · SIN a · COS a · SQRT n · ROUND n

            
; comment
to the end of the line
